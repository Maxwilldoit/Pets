# Pets v0.1.0

此标签的 Linux 文件名校验未通过，未公开发行。正式发行版见 [v0.1.1](v0.1.1.md)。

首个桌面发行版，内置 11 只宠物，支持 Windows x64、macOS x64 / arm64 和 Linux x64。发行文件见 [GitHub Release v0.1.0](https://github.com/Maxworkinghard/Pets/releases/tag/v0.1.0)。

## 桌宠与宠物库

- Makima 更新至 1.1.0，新增「成功」「失败」「录制中」「暂停」动作，并更新对应的 Codex 状态映射。
- 在控制面板浏览、搜索和预览宠物，从详情中将喜欢的宠物设为桌宠。
- 桌宠支持点击切换动作、拖动与甩动、右键菜单、大小调整和像素级点击穿透；可在设置中开启自动走动、随机动作与开机自启。
- 支持导入本地宠物文件夹，使用 GIF / APNG / WebP 动图、PNG 帧序列或精灵图素材，也可将宠物导入 Codex。
- 托盘常驻，并记住上次使用的宠物、位置和设置。

## 界面与交互改进

- 移除宠物卡片悬停时的召唤入口，顶部桌宠状态区隐藏重复操作入口。
- 合并标题栏与控制面板布局，统一深色与浅色主题。
- 设置页只保留功能名称、操作控件和文件夹路径，移除说明小字。
- 修正拖拽边界：宠物的可见底部不会越过任务栏上沿；关闭重力时也遵循显示器工作区边界。
- 改进不同高度、包含负坐标的多显示器布局下的拖拽边界处理。

## 下载与安装

根据系统和处理器选择对应文件，发行包内已包含宠物素材，无需另装 Node.js。

| 系统 | 文件 | 安装方式 |
| --- | --- | --- |
| Windows x64 | `Pets-0.1.0-windows-x64-setup.exe` | 运行安装程序并按提示完成安装。 |
| Windows x64 | `Pets-0.1.0-windows-x64-portable.exe` | 直接运行便携版。 |
| macOS Intel（x64） | `Pets-0.1.0-macos-x64.dmg` | 打开 DMG，将 Pets 拖入「应用程序」。 |
| macOS Intel（x64） | `Pets-0.1.0-macos-x64.zip` | 解压后将 Pets.app 移入「应用程序」。 |
| macOS Apple Silicon（arm64） | `Pets-0.1.0-macos-arm64.dmg` | 打开 DMG，将 Pets 拖入「应用程序」。 |
| macOS Apple Silicon（arm64） | `Pets-0.1.0-macos-arm64.zip` | 解压后将 Pets.app 移入「应用程序」。 |
| Linux x64 | `Pets-0.1.0-linux-x64.AppImage` | 添加可执行权限后运行。 |
| Linux x64 | `Pets-0.1.0-linux-x64.deb` | 在 Debian / Ubuntu 等兼容系统中安装。 |

Linux AppImage 可在文件所在目录运行：

```bash
chmod +x Pets-0.1.0-linux-x64.AppImage
./Pets-0.1.0-linux-x64.AppImage
```

Debian / Ubuntu 等兼容系统可在文件所在目录安装 DEB：

```bash
sudo apt install ./Pets-0.1.0-linux-x64.deb
```

## 文件校验与签名状态

Release 附带 `SHA256SUMS`，列出各发行文件的 SHA-256。下载后可计算本地文件的摘要，并与清单中的对应条目核对。

- Windows：使用 PowerShell 的 `Get-FileHash -Algorithm SHA256 .\Pets-0.1.0-windows-x64-setup.exe`。
- macOS：使用 `shasum -a 256 Pets-0.1.0-macos-arm64.dmg`，Intel Mac 请替换为 x64 文件名。
- Linux：使用 `sha256sum Pets-0.1.0-linux-x64.AppImage`。

本次 Windows 发行文件没有代码签名；macOS 发行文件没有开发者签名，也未进行 Apple notarization（公证）。系统可能提示无法验证开发者或阻止打开。
